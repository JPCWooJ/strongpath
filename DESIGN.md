This file is not canonical governance. Use it only to help Impeccable understand StrongPath's visual lane. Canonical visual direction remains:

If this file conflicts with governance, governance wins.

## Visual Standard

StrongPath should look editorial, institutional, calm, and trustworthy.

It should not look like SaaS, influencer wellness, aggressive ecommerce, supplement marketing, generic startup design, or decorative design for its own sake.

## Color

- Deep Navy `#0B2545`: authority, hero sections, primary buttons.
- Warm Gold `#B8860B`: accent only, never a dominant surface.
- Near Black `#1A1D24`: primary body copy.
- Warm Gray `#5A6472`: secondary copy, captions, metadata.
- Warm White `#FAF8F5`: page background.
- Muted Teal `#2E6171`: sparse links or highlight accents.

## Typography

- Headlines: editorial serif direction, currently governed by repo tokens.
- Body and UI: readable sans-serif direction, currently governed by repo tokens.
- Body copy minimum: 18px desktop, 17px mobile.
- Body text weight must not drop below 400.
- Headline hierarchy must be visibly clear before decorative refinement.

## Layout

- Whitespace should create calm reading momentum.
- Avoid dense card stacks, nested cards, and competing CTAs above the fold.
- Each section should have one dominant action.
- Mobile layouts must preserve readable line length, tap comfort, and clean headline wrapping.

## Imagery

Prefer realistic editorial imagery, book-cover authority, real movement, caregiving realism, and research or academic visuals when they improve trust or comprehension.

Avoid posed active-senior stock, beach/yoga/sunset wellness imagery, gym selfies, transformation imagery, pharmaceutical-ad aesthetics, and decorative imagery that does not improve the reader's understanding.

## Impeccable Use

Use Impeccable for UI/UX critique, layout, spacing, typography, visual rhythm, polish, and anti-pattern detection.

Do not use Impeccable as a replacement for StrongPath governance, and do not invoke it for non-UI tasks unless explicitly requested.
