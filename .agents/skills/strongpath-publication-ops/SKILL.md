If a referenced source is missing, flag it as unresolved. Do not recreate it.

Execution rules:
- Put publication and GTM deliverables in repo-committed markdown files.
- Do not dump full launch, X, Beehiiv, KPI, or checklist packages into chat unless explicitly requested.
- Do not create duplicate planning docs.
- Do not create new governance unless explicitly requested.
- Keep changes scoped to the requested publication/distribution artifact.

Run the applicable checks:
- Google Search readiness check.
- StrongPath Google Search Playbook check.
- Internal-link checklist.
- Amazon affiliate module checklist.
- X distribution handoff checklist.
- Beehiiv handoff checklist.
- KPI row / measurement checklist.

Exclude:
- strategy creation
- topic selection authority
- editorial claim judgment
- UX judgment
- final X voice authority
- Beehiiv send approval
- Google Business Profile posting
- new agent creation
- new governance creation
- broad growth-plan generation

Default return format:

```txt
FILES CHANGED
KEY CHANGES
VERIFICATION
COMMIT HASH
PUSH STATUS
UNRESOLVED ISSUES
```
