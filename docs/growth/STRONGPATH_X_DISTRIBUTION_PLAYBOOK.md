# StrongPath X Distribution Playbook

## Purpose

Tell GTM how to write and judge StrongPath X output.

Use `docs/governance/X_ALGORITHM_OPERATING_SYSTEM.md` for algorithm doctrine. This file governs public copy quality.

## 1. Account Role

`@StrongPathHQ` is the institutional editorial account and serious source-of-record.

Use it for:

- evidence-framed distinctions
- credible replies
- selective article distribution

Founder amplification is selective, not routine.

Use Jeff only when he adds:

- trust
- lived context
- mission clarity
- relationship warmth

Never use founder amplification as automatic second distribution.

## 2. Approved Lanes

Every post must map to one lane:

- sarcopenia / muscle loss
- strength as independence
- resistance training after 50 / 60
- protein, recovery, execution
- aging parents and caregiver support
- evidence older adults can regain strength
- GLP-1 / lean-mass risk when well sourced
- book/platform credibility
- clinician/PT/serious health-writing adjacency

## 3. Post Quality Gate

Every X post must contain one:

- misconception
- mechanism
- decision rule
- reader-relevant distinction
- evidence-backed implication
- founder context that changes why the topic matters

Do not publish if the post only converts keywords into social copy.

## 4. Hard Stops

Do not publish:

- article summaries
- "we published a new article" posts
- routine link drops
- repeated hooks with minor wording changes
- safe-but-bland wellness copy
- unsupported claims
- fear-led caregiver framing
- founder amplification that restates the institutional post
- posts that only convert search language into social copy

If nothing is sharp, do not post.

## 5. Article Amplification

Each article gets one primary new thought.

Later reframes are allowed only if each has a distinct new idea.

Do not assume every article deserves multiple posts.

Link only when the post is useful without the click.

## 6. Reply Rule

Reply before posting when a credible thread is a better distribution opportunity.

A reply must add one:

- distinction
- mechanism
- practical next step

Link only when directly useful.

Pass on threads that are spammy, supplement-heavy, politics-heavy, rage bait, low-trust, or off-lane.

## 7. Weekly X Decision

Decide one:

- promote
- reframe with a new thought
- retire
- hold
- run one controlled experiment
