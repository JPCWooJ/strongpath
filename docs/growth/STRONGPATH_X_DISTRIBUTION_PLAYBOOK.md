# StrongPath X Distribution Playbook

## Purpose

Tell GTM how to write and judge StrongPath X output.

This file governs public copy quality.

## Algorithm Realities

X rewards useful signal from the right audience.

Operate from these rules:

- relationship memory and topic consistency compound distribution
- useful replies can be stronger distribution assets than standalone posts
- negative feedback hurts more than casual likes help
- links must extend value, not replace it
- repeated hooks, repeated links, and bursts of similar posts weaken account quality
- post only when the unit of value is strong
- judge performance by qualified signal, not raw impressions

## Low-History Account Rule

StrongPath is a low-history account.

Do not expect link posts to carry distribution alone.

Build the graph first:

- reply to credible on-lane accounts
- post no-link distinctions when no strong reply target exists
- use link posts selectively after the account has earned topic memory
- avoid wasting strong articles into a cold graph

## Daily Execution Standard

Before posting, GTM must decide:

1. Who is the intended audience?
2. What graph does this action build?
3. Is reply, no-link post, or link post the best move?
4. What qualified signal would make this worth repeating?
5. What is the risk of attracting the wrong audience?

If these cannot be answered, wait.

## 1. Account Role

`@StrongPathHQ` is the institutional editorial account and serious source-of-record.

Use it for:

- evidence-framed distinctions
- credible replies
- selective article distribution

Founder amplification is selective, not routine.

Use Jeff only when he adds:

- trust
- lived context
- mission clarity
- relationship warmth

Never use founder amplification as automatic second distribution.

## 2. Approved Lanes

Every post must map to one lane:

- sarcopenia / muscle loss
- strength as independence
- resistance training after 50 / 60
- protein, recovery, execution
- aging parents and caregiver support
- evidence older adults can regain strength
- GLP-1 / lean-mass risk when well sourced
- book/platform credibility
- clinician/PT/serious health-writing adjacency

## 3. Post Quality Gate

Every X post must contain one:

- misconception
- mechanism
- decision rule
- reader-relevant distinction
- evidence-backed implication
- founder context that changes why the topic matters

Do not publish if the post only converts keywords into social copy.

## 4. Hard Stops

Do not publish:

- article summaries
- "we published a new article" posts
- routine link drops
- repeated hooks with minor wording changes
- safe-but-bland wellness copy
- unsupported claims
- fear-led caregiver framing
- founder amplification that restates the institutional post
- posts that only convert search language into social copy

If nothing is sharp, do not post.

## Post / Reply / Wait Decision

Before posting, choose one:

- reply if a credible on-lane conversation exists
- post no-link if StrongPath has one useful standalone idea
- post link only if the post is valuable without the click
- wait if the idea is weak, repetitive, off-lane, or likely to attract the wrong audience

Do not post to fill cadence.

## 5. Article Amplification

Each article gets one primary new thought.

Later reframes are allowed only if each has a distinct new idea.

Do not assume every article deserves multiple posts.

Link only when the post is useful without the click.

Do not post bursts of similar article links.

Space reframes only when each one has a distinct idea.

## 6. Reply Rule

Reply before posting when a credible thread is a better distribution opportunity.

A reply must add one:

- distinction
- mechanism
- practical next step

Link only when directly useful.

Prioritize credible replies over quota posting.

Pass on threads that are spammy, supplement-heavy, politics-heavy, rage bait, low-trust, or off-lane.

## Credible Target Rule

A credible target is:

- on-lane
- serious
- followed by or interacting with the audience StrongPath wants
- not rage bait, supplement spam, politics-heavy, or low-trust
- a place where StrongPath can add a distinction, mechanism, or practical next step

Bad adjacency is worse than no adjacency.

## Graph-Building Targets

Prioritize accounts and threads connected to:

- physical therapists
- geriatric clinicians
- strength coaches with evidence discipline
- serious health journalists
- aging researchers
- caregiver communities
- GLP-1 / lean-mass discussions when well sourced
- older-adult strength and independence conversations

Avoid:

- supplement promoters
- anti-aging influencers
- rage-bait health accounts
- politics-heavy accounts
- generic motivation accounts
- low-trust virality accounts

The goal is not more followers. The goal is repeated exposure to the right network.

## Weak Signal Diagnosis

Before deciding an idea failed, diagnose:

- graph: did the right audience have any chance to see it?
- hook: did the first line create a clear reason to keep reading?
- format: was this better as a reply, no-link post, or link post?
- timing: was the post buried by cadence or repetition?
- fit: did it strengthen StrongPath's topic identity?
- conversion: did attention move to article, email, quiz, book, or profile?

Do not repost weakly. Reframe only with a better diagnosis.

## Conversion Path Rule

Every X action should have one intended next step:

- profile visit
- article click
- newsletter signup
- quiz start
- book page visit
- credible reply
- relationship-building interaction

Do not post if the next step is unclear.

A post can succeed without a click if it builds the right graph.
A link post fails if it earns clicks from the wrong audience.

## 7. Weekly X Decision

Choose based on qualified signal, not effort invested.

Decide one:

- promote
- reframe with a new thought
- retire
- hold
- run one controlled experiment

Do not promote an angle that earned reach without qualified engagement.
