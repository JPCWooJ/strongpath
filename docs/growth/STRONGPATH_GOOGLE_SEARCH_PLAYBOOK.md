# StrongPath Google Search Playbook

## Purpose

Use Google Search data as a task-specific GTM reference.

This file is not daily GTM first-read material.

Search intent may inform public angles, but search language must not become public copy.

## Use Search Data For

- organic landing-page behavior
- search-to-email conversion
- search-to-quiz conversion
- search-to-book conversion
- affiliate conversion
- topic-demand review
- CTA weakness
- source-quality review

## Track

- organic clicks
- organic CTR
- top organic landing pages
- high-impression / low-CTR pages
- indexed pages / indexing errors
- organic signup pages
- organic quiz starts
- organic book or affiliate clicks

## Ignore

Do not use search to create:

- keyword-shaped X posts
- generic summaries
- thin content
- off-lane expansion
- social copy copied from search phrasing
- article launch process
- internal-linking process

## Search Decisions

Every search review ends with one decision:

- distribute more
- improve CTA
- reframe angle
- hold
- escalate to Editorial
- escalate to CTO
- escalate to Founder

## Add-Back Rule

Deleted search process returns only if the same execution failure happens twice and the missing rule would have changed the decision.
