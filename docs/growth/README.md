# StrongPath Growth

`docs/growth/` stores active GTM operating references and approved growth deliverables.

GTM should not create launch packages by default.

GTM deliverables belong here only when they are actually reusable and proven useful.

One-off article launch assets should not be created unless explicitly approved.

Codex responses for GTM work should remain short:

- files changed
- key changes
- commit hash
- unresolved issues
