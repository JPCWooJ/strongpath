# StrongPath Growth Deliverables

## Purpose

Canonical home for GTM, launch, email, social, recirculation, and distribution markdown deliverables.

## Structure

- `templates/`: reusable launch package templates
- `checklists/`: reusable launch QA and readiness checklists
- `launches/<slug>/`: article-specific launch assets

## Launch Package Standard

Each article launch should include:

- Beehiiv package
- X distribution package
- publication checklist
- recirculation notes
- homepage feature copy when needed
- final launch checklist

## Codex Chat Output

For GTM deliverables, Codex should return only:

- file paths changed
- concise diff summary
- commit hash
- unresolved issues

Do not print full GTM payloads into chat unless explicitly requested.
