## Public Output Standard

Every GTM public asset must contain at least one of:

- sharp contrast
- non-obvious insight
- mechanism
- decision rule
- practical implication

Reject any post, newsletter blurb, or distribution copy that merely summarizes the article.

Test before publishing:

- Could a generic wellness brand have written this?
- Is it useful without a click?
- Does it create a clear next action?
- Does it strengthen StrongPath’s topic identity?

If the answer is weak, do not publish.

## GTM Operating Standard

Default order:

1. Identify the asset.
2. Extract the one non-obvious idea.
3. Turn it into one sharp public angle.
4. Attach one clear CTA.
5. Measure signal quality and decide the next move.

Do not publish generic article summaries.
Do not create launch packages by default.
Do not use founder amplification unless founder context materially improves trust.
