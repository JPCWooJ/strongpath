# StrongPath Governance

`docs/governance/` is the authoritative governance source for StrongPath.

Use these files before implementation work, design refinement, content planning, or agent handoff. If another repo document conflicts with this directory, this directory wins unless the founder gives a newer explicit instruction.

## Governance Hierarchy

This README is the canonical source for governance authority order.

1. Founder instructions
2. `AGENT_RULES.md`
3. `CODEX_EXECUTION_STANDARD.md`
4. Role-specific agent profiles
5. Lane-specific governance files
6. Task-specific prompts

Role-specific profiles:
- `CTO_AGENT_PROFILE.md`
- `CHIEF_OF_STAFF_AGENT_PROFILE.md`
- `EDITORIAL_SYSTEMS_AGENT_PROFILE.md`
- `GTM_AGENT_PROFILE.md`
- `UIUX_AGENT_PROFILE.md`

Lane-specific governance includes brand, design, personas, editorial, GTM, metrics, publishing, keyword, and product-backlog files.

## Archive

Archived governance files live in `archive/governance/` or `docs/governance/archive/`.

Those files are non-authoritative and retained for historical reference only. Do not use archive files as implementation guidance unless the founder explicitly asks for historical context.
