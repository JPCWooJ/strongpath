# METRICS.md

## Purpose

Metrics exist to force better GTM decisions.

Do not build dashboards.
Do not report for the sake of reporting.
Do not optimize vanity metrics.

## Track

Track only:

- qualified article clicks
- newsletter signups
- signup conversion rate
- quiz starts
- quiz completion rate
- book clicks
- affiliate clicks where applicable
- saves/bookmarks
- credible replies
- relevant profile visits
- organic clicks
- organic CTR
- top organic landing pages
- high-impression / low-CTR pages
- indexed pages / indexing errors
- one qualitative learning

## Ignore

Do not optimize around:

- raw impressions alone
- likes without qualified engagement
- follower growth from low-trust audiences
- traffic spikes without conversion path
- vanity dashboards
- complex attribution models
- reports that do not create a decision

## Weekly Review

Every weekly GTM review must answer:

1. What earned qualified attention?
2. What failed to earn signal?
3. What converted?
4. What changes next?

## Required Decision

Every review ends with one decision:

- promote
- reframe
- retire
- hold
- fix CTA

If there is no decision, the review failed.

## Add-Back Rule

Deleted metrics return only if the same execution failure happens twice and the missing metric would have changed the decision.
