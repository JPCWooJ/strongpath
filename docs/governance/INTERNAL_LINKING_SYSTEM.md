# Internal Linking System

## Purpose

- Govern StrongPath internal links.
- Help readers move from question to context to next action.
- Preserve topical authority, evidence separation, commerce boundaries, and non-orphaned pages.

## Core Rules

- Links are editorial guidance first, SEO support second.
- Every important page needs a clear incoming and outgoing path.
- Use fewer better links.
- Anchor text must be honest, specific, and claim-safe.
- Evidence links, internal links, book links, and commerce links have different jobs.

## Pillar / Satellite Rules

- Every satellite links to its parent pillar.
- Pillars link only to the most useful satellites.
- Link where the reader naturally needs context or next detail.
- Do not dump every cluster link into every pillar.
- Do not link to unfinished or thin pages as if complete.

## Contextual Links

Use contextual links for:

- definitions
- mechanisms
- safety boundaries
- deeper evidence
- execution steps
- caregiver or persona-specific guidance
- book credibility context

Avoid:

- linking every keyword occurrence
- repeating the same link unnecessarily
- stacking many links in one sentence
- inserting unrelated links for ranking

## Anchor Text

Good anchors:

- describe the destination
- use reader language
- stay narrower than evidence
- avoid hype and promises

Bad anchors:

- reverse sarcopenia
- prevent falls with this program
- cure muscle loss
- any product-outcome promise
- hidden affiliate destinations

## Link Separation

- Evidence links go to sources.
- Internal links go to StrongPath explanations or next steps.
- Commerce links go to buying or product actions.
- Book links go to credibility, origin, or deeper authority context.
- Do not use commerce links as evidence.
- Do not use the book page as proof for current health claims.

## Persona Pathways

- Margaret: peer-level problem -> mechanism -> execution.
- David: goodwill -> parent safety -> practical start.
- Dr. Chen: citation visibility -> limits -> non-clinical posture.

The link should fit the dominant reader moment.

## CTA Hierarchy

- Education next step.
- Quiz or assessment only when relevant and non-diagnostic.
- Book page for credibility or depth.
- Product/program only after education.
- Affiliate purchase only in clearly commercial context.

Use one primary CTA per article.

## Maintenance

Review links when:

- article publishes or refreshes
- pillar changes
- URL changes
- page merges, deprecates, or archives
- commerce destination changes
- citation or claim governance changes
- a better next step exists

## Pass / Fail

Pass when:

- links serve the reader
- anchors are accurate
- evidence and commerce stay separate
- satellite/pillar pathway is clear
- important pages are not orphaned

Fail when:

- anchor overclaims
- commerce link is used as proof
- book link is used as health-claim proof
- page publishes with no incoming path
- links create duplicate, circular, or confusing pathways

## Escalate

- Unsafe anchor text.
- Commerce-sensitive destination.
- Evidence/affiliate separation problem.
- URL change affecting authority.
- Orphan risk.
- Book link used as proof.
- Persona pathway feels fear-based, patronizing, or clinically misleading.
